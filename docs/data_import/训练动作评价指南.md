# IronLog 训练动作评价指南

> 状态：2026-07-16 建立；本文件是训练动作的证据审查、目录评价与评分口径权威。
>
> 范围：面向 IronLog 本地单人版的默认动作目录策展，不是训练处方、医疗建议或对个人安全性的保证。
>
> 本轮边界：完成 `ref/` 八段视频的可核查分析，并重评现有 63 条正式动作、18 条待实施候选和 10 条暂缓记录；**不向 IronLog 默认动作库引入新动作，不修改动作运行时字段或 UI 筛选能力**。

## 1. 使用方式与证据边界

评价结论必须同时回答四个不同的问题，不能用一个“最好”替代：

1. 该动作在已声明的目标下能扮演什么角色？
2. 在当前目录中，它是否提供了足够的新增价值？
3. 现有 IronLog 模型、记录方式、器械枚举和来源契约能否实施它？
4. 支撑结论的是已核验事实、合理推断，还是视频作者的观点？

文中标记含义如下：

- **[已验证]**：已核验当前代码、固定上游记录、视频时间对齐证据或外部一手/高质量研究。
- **[推断]**：从已验证材料得出的目录策展判断；应写明适用条件。
- **[视频观点]**：视频作者明确说出或展示的排序、训练建议或经验判断；不能单独证明效果、安全性、伤病预防或专项迁移。
- **[待核验]**：候选的来源、模型、记录方式或证据还不足以支持实施。

外部训练研究主要适用于健康成人、持续至少数周的训练干预。伤病、疼痛、孕期、术后、慢病、竞技专项或未成年人的动作选择，需要另行的个体评估；本指南不能替代该评估。

### 2.3 外部证据的统一校正

- **[已验证]** 阻力训练处方应先匹配目标、能力和训练状态；渐进负荷是长期适应所需的实施原则，而不是某个动作天然更高价值的证据。[ACSM 2009 立场声明](https://pubmed.ncbi.nlm.nih.gov/19204579/)
- **[已验证]** 2026 ACSM 立场声明以健康成人的系统综述为基础，强调不同目标的处方变量并不相同；因此不能用一张动作总榜同时裁定力量、肥大、功率和体能。[ACSM 2026 立场声明](https://pubmed.ncbi.nlm.nih.gov/41843416/)
- **[已验证]** 全活动范围在该系统综述中对力量和下肢肥大总体更有利，但这不是忽略疼痛、结构限制或专项局部范围的硬规则。[活动范围系统综述](https://pubmed.ncbi.nlm.nih.gov/34170576/)
- **[已验证]** 自由重量与器械的直接比较没有显示一种器械类型在最大力量、肥大和跳跃表现上普遍胜出；目录不应给“自由重量”或“器械”固定加分。[自由重量与器械 Meta 分析](https://pmc.ncbi.nlm.nih.gov/articles/PMC10426227/)
- **[已验证]** 动态阻力训练的迁移具有任务特异性；“动作本身 1RM 更高”不能直接写成全面力量或专项表现更好。[任务特异性系统综述](https://pubmed.ncbi.nlm.nih.gov/40314751/)
- **[推断]** 因此，视频能提供动作候选、可能的技术观察点和待核验问题；外部证据与当前模型才决定目录结论。视频的排名、肌电、单项研究转述和安全宣传均不进入本指南的事实层。

## 3. 统一评价方法论

### 3.1 先定目标，再谈动作

每次评价先从下列一个主目标出发；若一个动作有多个作用，选择本轮要解决的主目标，而不是把所有作用相加：

- **力量特异性**：目标动作/模式、负荷、活动范围、收缩方式和速度是否匹配。
- **肌肥大刺激**：能否在可控范围内累积足够训练量，并允许稳定接近目标用力程度。
- **功率/爆发**：是否能在已具备相应技术和耐受条件下快速表达力量；需要单列冲击、落地和技术要求。
- **核心/躯干控制**：目标是抗伸展、抗旋转、抗侧屈、屈曲、负重行走或其他明确任务，不能笼统称“练核心”。
- **心肺/体能**：优先看可持续记录的距离、时间、负荷和场地条件，而不是把高疲劳复合动作自动称为更好。
- **局部辅助/单侧控制**：说明它补的是哪个已知缺口，不把它伪装成所有人的主力动作。

### 3.2 再过四道准入门

1. **证据与语义门**：有可追溯来源或明确的自编契约；名称、步骤、器械和目标不自相矛盾。
2. **实现门**：当前 `ExerciseDoc`、器械枚举、唯一记录方式和四项记录配置可以准确表达；否则标为“阻塞”，而非低分入库。
3. **条件门**：动作可在使用者的可控范围、技术能力、设备、监督和症状状态下完成。疼痛、已知伤病或无法控制代偿时，结论应改为“需调整/转介”，而不是给动作添加一个虚假的通用风险分。
4. **目录身份门**：它须补足不同的主角色、目标条件、记录价值，或有清楚的替代路径；不能只因名称流行、变式较多或视频等级高而进入目录。

### 3.3 最终输出是角色，不是永久名次

通过准入门的动作，使用以下结论词：

- **主力候选**：在给定目标下可稳定渐进，并且目录价值清晰。
- **辅助候选**：目标明确，但更适合补强、容量或局部训练。
- **条件替代**：在特定器械、技术、可控范围或疲劳条件下可替代主力。
- **储备/暂缓**：当前覆盖增量低、证据不充分或实施收益不清晰。
- **阻塞**：当前模型、记录方式、来源契约或安全边界未满足；不是对动作训练价值的否定。

5. 重评时保留旧结论和变更原因；不得仅为了让分数或 A/B 数量看起来均匀而改写结论。

## 7. 筛选与评分权威

本节是 IronLog 默认动作目录的唯一评分口径。它替代 v1 的“通用性/训练价值/可获得性/动作覆盖/可记录性/冗余惩罚/数据质量”单一总分。任何候选表、实施方案、代码注释或临时讨论不得另设可与本节竞争的评分模型。

### 7.1 评分前的准入门

候选必须依次记录以下四门的状态，且 `R` **不得**逆转任何一门的结论。G0、G1 是实施硬门；G2 可以在条件被明确写出时“条件通过”，G3 可以在角色或替代路径明确时“条件通过”。G2 的条件无法写清、或 G3 没有目录身份时，结论为“暂缓”，而不是靠高分入库。

| 门 | 必须满足的条件 | 未通过的处理 |
|---|---|---|
| G0：来源与语义 | 固定上游记录或明确自编契约；名称、步骤、器械和目标可解释 | 停止入库；不得借用近似动作的 provenance |
| G1：模型与记录 | 当前字段、器械枚举、唯一记录方式与四项配置能表达核心训练量 | 记录模型阻塞项；先更新字段契约矩阵和实现，再评价实施 |
| G2：使用条件 | 能写出可控 ROM、技术/监督、设备和不适信号等边界 | 条件写清即为条件通过；无法写清时停止入库或转介，不得写通用安全率、必然防伤或医疗结论 |
| G3：目录身份 | 有与现有动作不同的主角色、目标条件、记录价值或明确替代路径 | 角色/替代路径明确即为条件通过；否则标为储备/暂缓，不因名称流行、变式多或视频等级高而入库 |

### 7.2 四维目录优先级分

仅在 G0、G1 通过，且 G2、G3 已形成可执行的条件与角色结论后，为**已经声明的单一主目标**计算 `R`。多目标动作不累加多个目标分；改评价目标时必须重新打分。

```text
R = T（目标适配） + P（可渐进与可记录） + U（目录独特性） + Q（证据与数据置信度）
```

每项取 0–3：

| 维度 | 0 分 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|---|
| T：目标适配 | 主目标不明确或不匹配 | 只能间接服务目标 | 可作为条件替代/辅助 | 直接、清晰地服务本轮主目标 |
| P：可渐进与可记录 | 当前组字段不能表达核心训练量 | 可记录但关键进阶变量缺失 | 可用负荷/次数/时间/距离中的一条稳定推进 | 进阶和核心训练量均可明确、稳定地记录 |
| U：目录独特性 | 仅是低价值微变体 | 与现有动作高度重叠 | 有设备、方向、单侧性或角色差异 | 补足尚无主角色或不可替代的记录价值 |
| Q：证据与数据置信度 | 来源/语义未核验或有关键矛盾 | 只能依赖间接推断、人工语义扩展或显著信息损失 | 来源、字段和一般训练证据充分，仍缺直接比较证据 | 有直接且适用的人群/目标证据，并且字段与实现无损匹配 |

`R` 的解释：

- **10–12**：可作为优先候选；仍需给出角色和条件，不能称“总体最佳”。
- **8–9**：可作为条件替代、辅助或储备候选；须写明限制与覆盖取舍。
- **0–7**：通常暂缓；只有经人工批准且有不可替代价值时才保留审计记录。
- **G0 或 G1 阻塞**：`R` 仅用于说明潜在目录价值，不具有入库资格。
- **G2 条件未写清或 G3 暂缓**：即使列出 `R`，也不得把它解读为入库优先级；应先补足条件或目录身份。

### 7.3 评分输出格式与禁止项

每个候选必须写成：

```text
主目标与角色；G0/G1/G2/G3 状态（通过、待核、条件通过、阻塞或暂缓）；T/P/U/Q=R；结论；条件或替代路径；证据层级。
```

禁止：

- 用 `R` 宣称动作对所有人更安全、更有效或更适合专项。
- 因自由重量、器械、多关节、单侧、复杂或流行而自动加减分。
- 用视频作者的 S/A/B/F、肌电、相关性或未给出书目信息的研究转述填充 Q=3。
- 把目录评分写入 `ExerciseDoc`、生成产物、个人成绩、页面筛选或模板筛选逻辑。
- 在未通过来源或模型门时，通过降低标准、伪造来源、重命名近似记录或新增无契约字段绕过阻塞。

### 7.4 复审触发与审计

目录每次增删、字段模型/记录方式变更、上游版本变更、目标角色调整或出现直接适用证据时，必须重评受影响动作的 G0–G3 与 `T/P/U/Q=R`。保留旧版本评分、变更原因、证据链接和受影响的运行时/生成链状态；A/B 目录批次标签如需改变，必须同步候选表、生成哈希、数量断言和实施验证。
