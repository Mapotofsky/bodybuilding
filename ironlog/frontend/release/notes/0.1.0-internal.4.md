# IronLog录铁 0.1.0-internal.4

Android 内部测试版。最低支持 Android 7.0（API 24）。

## 本次更新

- 修复训练时间偏移、应用进入后台后的计时，以及重复创建未完成训练的问题。
- 训练和编辑时长改为分别填写分、秒；改进动作详情与训练中的记录展示。
- 调整 Android 系统栏与返回行为，并完善动作库及训练页面的交互。

## 安装与数据

下载本页的签名 APK 后安装。覆盖升级必须使用与已安装版本相同的签名密钥；升级前建议先完成一次成功的 WebDAV 同步。请勿通过卸载应用或清除应用数据来升级，这会删除本地训练记录。Android 设备可能需要允许浏览器或文件管理器“安装未知应用”。

本版数据格式为 v9，可读取并迁移 v5 至 v8 的已有数据；v4 及更早版本、未来版本或损坏的快照会阻止加载，不会自动清空。迁移后旧版应用不保证能读取新数据，因此不要依赖直接安装旧 APK 回滚。上一内部测试版为 `0.1.0-internal.3`。

## 当前限制

- WebDAV 同步发生同一记录冲突时，按更新时间采用 last-write-wins；远端 `backups/` 尚无自动清理。
- 浏览器开发版的密码存储安全等级低于 Android 版。
- 暂无用户可操作的数据导入、导出界面。
